# Welcome to Lazarus

<img src="../build/icon.svg" alt="Lazarus icon" width="96" align="right">

A **fast**, *clean* Markdown editor with a live preview that keeps up with you.
Write on the left, read on the right — or hide either side with ⇧⌘P.

> "The best writing tool is the one that gets out of the way."

## What's in the box

- **Tabs** with their own undo history, cursor and scroll position
- **Session restore** — quit mid-sentence, come back to exactly where you were
- **Quick open** (⌘P) across your folder and recent files
- **Focus mode** and **typewriter scrolling** for long-form writing
- Export to self-contained **HTML** or **PDF**

Follow a link to another document and it opens in a new tab:
[Math & diagrams](math-and-diagrams.md) · [Code](code.md) · [Weekly planning](notes/weekly-planning.md)

## Shortcuts worth learning first

| Action        | Shortcut | Notes                              |
| ------------- | :------: | ---------------------------------- |
| Quick open    |   ⌘P     | Fuzzy match on file names          |
| Bold / italic |  ⌘B / ⌘I | Toggles — press again to remove    |
| Heading 1–6   | ⌘1 … ⌘6  | Works on the current line          |
| Focus mode    |   ⇧⌘F    | Dims everything but this paragraph |
| Dark mode     |   ⇧⌘D    | Or just follow the system          |

Type `/` at the start of a line for tables, code fences, diagrams and more.
